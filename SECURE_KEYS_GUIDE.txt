HOW TO USE THIS FILE
--------------------
1. Pick a key set from Option 1-5 below
2. Copy the Node command -> paste into Node Serial Monitor
3. Copy the HQ command -> paste into HQ Serial Monitor
4. If you use PHP backend, also update security_config.php

================================================================================
                          OPTION 1 (Recommended)
================================================================================

Node Serial Command:
SETKEYS,AES128=AquaNode2024AES1,AUTH=AQUA77

HQ Serial Command:
SETKEYS,AES=AquaNode2024AES1,API=smartponic-hq-key,HMAC=smartponic-hq-signature-secret

================================================================================
                     CUSTOM KEY TEMPLATES (If you want your own)
================================================================================

Node Serial Command Template:
SETKEYS,AES128=<YOUR_16_CHAR_AES_KEY>,AUTH=AQUA77

HQ Serial Command Template:
SETKEYS,AES=<YOUR_16_CHAR_AES_KEY>,API=smartponic-hq-key,HMAC=smartponic-hq-signature-secret

NOTE: AES key MUST be exactly 16 characters!
      Auth key MUST be exactly 6 characters (AQUA77) for now!

================================================================================
                     PHP BACKEND UPDATE (security_config.php)
================================================================================

If you use Option 1-5, your PHP security_config.php keys stay DEFAULT:

    define('SMARTPONIC_API_KEY', 'smartponic-hq-key');
    define('SMARTPONIC_HMAC_SECRET', 'smartponic-hq-signature-secret');

Only change these if you also changed API key or HMAC in HQ SETKEYS command.

================================================================================
                          VERIFICATION COMMANDS
================================================================================

After setting keys, verify with:

Node:
SHOWKEYS

HQ:
SHOWKEYS

Both should show your new AES key (16 characters) and API/HMAC as configured.

================================================================================
                          RESET TO DEFAULTS
================================================================================

Node:
CLEARKEYS

HQ:
CLEARKEYS

This resets all keys to the original hardcoded defaults.

================================================================================
                          KEY REQUIREMENTS QUICK REF
================================================================================

Key Type          | Node Format                  | HQ Format
-----------------|------------------------------|----------------------------------
AES Key (16 char)| SETKEYS,AES128=YOUR_KEY     | SETKEYS,AES=YOUR_KEY
Auth Key         | SETKEYS,...,AUTH=YOUR_KEY    | (hardcoded in HQ for now)
API Key          | N/A                          | SETKEYS,...,API=YOUR_KEY
HMAC Secret      | N/A                          | SETKEYS,...,HMAC=YOUR_KEY

IMPORTANT: Keep AES key the SAME on Node and HQ!
           Keep AUTH key the SAME on Node and HQ (or update getRuntimeAuthKey())
           Keep API key the SAME on HQ and PHP!
           Keep HMAC secret the SAME on HQ and PHP!
